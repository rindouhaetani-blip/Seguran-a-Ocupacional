# 🛡️ Segurança no Trabalho

Um site informativo e educativo sobre segurança ocupacional, prevenção de acidentes e saúde do trabalhador.

## 📋 Conteúdo

- **Guias de Segurança**: Normas e procedimentos de segurança
- **Equipamentos de Proteção**: Informações sobre EPIs
- **Prevenção de Acidentes**: Dicas e boas práticas
- **Legislação**: Leis e regulamentações trabalhistas
- **Recursos**: Materiais educativos e templates

## 🚀 Como Começar

1. Clone o repositório
2. Navegue até a pasta do projeto
3. Abra `index.html` no seu navegador

## 📁 Estrutura

```
seguranca-traballho/
├── index.html          # Página principal
├── css/                # Estilos
├── js/                 # Scripts
├── assets/             # Imagens e recursos
└── pages/              # Páginas adicionais
```
